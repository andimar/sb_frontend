# Font locali

Roboto (peso 100–900) e Yanone Kaffeesatz (200–700), stile normale,
sono distribuiti localmente per evitare richieste dei visitatori a Google Fonts.
Le dichiarazioni sono in `src/styles/tailwind.css`, con `font-display: swap`.
La build copia font e licenze in `dist/assets/fonts`.

Origine: repository ufficiale https://github.com/google/fonts,
directory `ofl/roboto` e `ofl/yanonekaffeesatz`, scaricati il 2026-11-14.
Vedere i file OFL per licenze e attribuzioni. Non occorrono modifiche al database.
